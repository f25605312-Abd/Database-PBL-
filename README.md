# Database-PBL-
1. Project Overview
Title: Student Enrollment System
Purpose: Demonstrates SQL database design and integration with a Python Tkinter GUI.
Features: CRUD operations (Create, Read, Update, Delete) with fields like StudentID, Name, CGPA, AdmissionDate.

Database Setup
Copy text in create_table.sql to create the schema.
Copy text in table_data.sql to populate tables with sample records.
Copy text in advancedqueries and triggers.sql to test advanced queries and triggers(joins, aggregate functions, etc.).

Application Integration
Python Tkinter GUI connected to MySQL using mysql-connector-python.
GUI allows adding, viewing, updating, and deleting student records.
Fields handled: StudentID, Name, CGPA.
Data entered in the GUI is reflected in the database instantly.
The compiler is PyCharm.

How to Run the App
Install Python and PyCharm.
Install dependencies:
Code
pip install mysql-connector-python
Open app.py in PyCharm.
Update connection details (user, password, database) to match your MySQL setup.
Run the app → GUI window opens.
Use buttons to perform CRUD operations.
